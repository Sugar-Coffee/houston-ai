Shared look for every tape, kept here so the three cannot drift apart.
Paste the `Set` block into each tape; VHS has no include directive.

    Set Shell "bash"
    Set FontSize 15
    Set Width 1600
    Set Height 900
    Set Padding 20
    Set Margin 50
    Set MarginFill "#181825"
    Set BorderRadius 12
    Set WindowBar "Colorful"
    Set WindowBarSize 42
    Set Theme "Catppuccin Mocha"
    Set Framerate 24
    Set TypingSpeed 45ms
